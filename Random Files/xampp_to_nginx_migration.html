🟢 BACKEND MIGRATION GUIDE (Node.js Express + MariaDB + Redis)

Backend Team Specification

The Node.js server now runs bound to 127.0.0.1 (localhost) instead of public 0.0.0.0. Express is configured to trust Nginx proxy headers, and database connectivity is pointed to standalone MariaDB and Memurai Redis services.

Nginx Reverse Proxy Location Block (for Backend API & WebSockets)

# Nginx config section for API & Socket.io Reverse Proxy
location /api/ {
    proxy_pass http://127.0.0.1:8000/api/;
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_read_timeout 300s;
}

location /socket.io/ {
    proxy_pass http://127.0.0.1:8000/socket.io/;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade"; # WebSocket Upgrade
    proxy_read_timeout 300s;
}
