Architecture Migration Guide

Replacing XAMPP / Apache with Nginx

A complete technical guide to building a crash-resilient, production-ready stack for React, Node.js, and Native MariaDB on Windows.

⚡

Why Make This Migration?

Your team experienced crashes because XAMPP's Apache web server was built for PHP (LAMP/WAMP stack) using heavy process-per-request threads (mod_proxy). Under high traffic or concurrent API calls from React, Apache exhausts system memory and crashes the entire XAMPP control panel, taking down your database.

By migrating to Nginx + Native MariaDB:

  • Nginx handles 10,000+ concurrent requests using only ~15MB of RAM.
  • React static assets are served directly from disk at maximum speed.
  • Native MariaDB runs as an isolated Windows Service that never restarts when web servers change.

Production Nginx Configuration (nginx.conf)

File Location: C:\nginx\nginx-1.30.4\conf\nginx.conf

server {
    listen       80;
    server_name  localhost;

    # Enable Gzip Compression for fast React asset loading
    gzip on;
    gzip_types text/plain text/css application/json application/javascript;

    # ----------------------------------------------------
    # 1. REACT FRONTEND (Direct Static File Serving)
    # ----------------------------------------------------
    location / {
        root   "C:/path/to/your/react-app/dist";
        index  index.html index.htm;
        
        # Fixes React Router SPA 404 error on page refresh
        try_files $uri $uri/ /index.html;
    }

    # Cache Static Assets (JS, CSS, Images)
    location /assets/ {
        root "C:/path/to/your/react-app/dist";
        expires 1y;
        add_header Cache-Control "public, no-transform";
    }

    # ----------------------------------------------------
    # 2. NODE.JS BACKEND API PROXY
    # ----------------------------------------------------
    location /api/ {
        proxy_pass         http://127.0.0.1:3000/; # Node.js Backend Port
        proxy_http_version 1.1;
        
        proxy_set_header   Host $host;
        proxy_set_header   X-Real-IP $remote_addr;
        proxy_set_header   X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header   X-Forwarded-Proto $scheme;

        # WebSocket support
        proxy_set_header   Upgrade $http_upgrade;
        proxy_set_header   Connection "upgrade";
    }
}

Step-by-Step Setup Checklist

  1. Verify Native MariaDB: Ensure MariaDB is running as an automatic Windows Service (Get-Service MariaDB* in PowerShell).
  2. Build React Project: Run npm run build in your React project directory to generate the dist/ folder.
  3. Update nginx.conf: Paste the configuration above into C:\nginx\nginx-1.30.4\conf\nginx.conf with your exact folder paths.
  4. Test Configuration Syntax: 
    cd C:\nginx\nginx-1.30.4
.\nginx.exe -t
  5. Start Nginx: 
    start nginx
  6. Access Application: Open http://localhost in your browser!
