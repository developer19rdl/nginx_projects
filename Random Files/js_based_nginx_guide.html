Production Migration Guide

Js Based Application: Nginx Architecture & Integration

Technical guide detailing the transformation of the React 19 (Vite) client and Express Node.js backend into a high-performance, single-origin Nginx production stack.

🚀

1. Executive Summary

The Js Based application has been successfully migrated from a multi-port development layout to a unified production architecture powered by Nginx (Port 80).

Migration Status: DEPLOYED & VERIFIED
Nginx is currently serving compiled React static assets from disk and reverse-proxying Express API calls on http://localhost/ with 0 CORS overhead.
Metric / Feature Before (Dev Mode) After (Nginx Production Stack)
Access URL Frontend: :5173 | Backend: :5000 Unified Single Origin: http://localhost/ (Port 80)
CORS Handling Required explicit CORS middleware & origin permissions Zero CORS needed (Frontend and API share Port 80)
Static Asset Delivery Vite dev server bundle transformation overhead Kernel sendfile direct disk serving via Nginx

2. Detailed Summary of Changes Performed

Change 1: Frontend Client API Base URL Modification

Updated Js Based/client/src/api.js to use relative URLs by default instead of a hardcoded backend port (http://localhost:5000).

- const API_BASE_URL = import.meta.env.VITE_API_URL || "http://localhost:5000";
+ const API_BASE_URL = import.meta.env.VITE_API_URL || "";

export async function fetchDashboardData() {
  const res = await fetch(`${API_BASE_URL}/api/dashboard`);
  if (!res.ok) {
    throw new Error(`Dashboard API request failed with status ${res.status}`);
  }
  return res.json();
}
Why this change matters: When API_BASE_URL is empty (""), the browser fetches /api/dashboard relative to the current window host (Port 80). Nginx receives /api/dashboard on port 80 and proxies it internally to 127.0.0.1:5000/api/dashboard.

Change 2: Compiled Optimized Production Build

Ran Vite production build command in Js Based/client:

npm run build

This generated optimized static HTML, CSS, and JS chunks in Js Based/client/dist:

  • dist/index.html (HTML Entry Point)
  • dist/assets/index-Bd7QtbEb.js (React 19 Bundle)
  • dist/assets/index-nr5b7YGH.css (Compiled Stylesheet)

Change 3: Nginx Configuration Updates

Modified C:\nginx\nginx-1.30.4\conf\nginx.conf to declare both the static root and reverse proxy location blocks:

server {
    listen       80;
    server_name  localhost;

    # 1. REACT FRONTEND (Direct Static File Serving & SPA Fallback)
    location / {
        root   "C:/Users/Administrator/source/repos/Honda/Other Projects/Nginx demo/Js Based/client/dist";
        index  index.html index.htm;
        try_files $uri $uri/ /index.html;
    }

    # 2. EXPRESS NODE.JS BACKEND PROXY
    location /api/ {
        proxy_pass         http://127.0.0.1:5000/api/;
        proxy_http_version 1.1;
        proxy_set_header   Host $host;
        proxy_set_header   X-Real-IP $remote_addr;
        proxy_set_header   X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header   X-Forwarded-Proto $scheme;
    }
}
