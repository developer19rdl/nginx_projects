2. Nginx Location Block for Frontend

Nginx handles static file delivery directly from the compiled /build directory, with fallback to /index.html for single-page routing (SPA):

# Nginx config section for React Frontend
location / {
    root "C:/Users/Administrator/source/repos/Honda/Other Projects/Nginx demo/Mllik/MallikNewVersion/build";
    try_files $uri $uri/ /index.html;
}
