🏗️ 1. ARCHITECTURE COMPARISON (OLD VS NEW)

🌐 2. ON-PREMISES STATIC IP REPLACEMENT GUIDE

Deployment IP Rules

When deploying to any on-premises client server, replace <SERVER_LAN_IP> with the client's actual static IP address (e.g., 192.168.1.15). Below is the breakdown of IPs to change vs IPs that MUST remain 127.0.0.1 / localhost:

1. Settings to UPDATE to Client Static IP (e.g., 192.168.1.15)

Component File Path Setting / Directive Value to Set
Nginx conf/nginx.conf server_name server_name 192.168.1.15 localhost;
Backend .env app/.env APP_URL APP_URL = http://192.168.1.15
Backend Socket app/app/sockets/index.js cors.origin origin: "http://192.168.1.15"
Database Host app/.env DB_HOST 192.168.1.18 (or 127.0.0.1 if DB is local)

2. Settings that MUST REMAIN 127.0.0.1 / localhost (DO NOT CHANGE)

Component File Path Setting Fixed Value Why Keep 127.0.0.1?
Backend Host app/.env APP_HOST 127.0.0.1 Keeps Node / Executable bound locally; secured behind Nginx
Nginx API Proxy conf/nginx.conf proxy_pass /api/ http://127.0.0.1:8000/api/ Nginx connects to local Node/EXE instance internally
Nginx Socket Proxy conf/nginx.conf proxy_pass /socket.io/ http://127.0.0.1:8000/socket.io/ Nginx proxies local WebSocket port internally
Redis Client app/app/config/redisCleinet.js socket.host 127.0.0.1 Memurai/Redis service listens on local port 6379
Frontend API URL MallikNewVersion/.env REACT_APP_API_URL /api/ Relative route — automatically uses client browser IP!

5. Nginx On-Premises Configuration (`nginx.conf`)

5.1 Standard Configuration — React served at /MallikEngineering/

⚠️ Key Nginx Change: Because package.json homepage is now "/MallikEngineering/", Nginx must use location /MallikEngineering/ with alias (NOT root) pointing directly to the build/ folder. A redirect from / to /MallikEngineering/ is also added so users don't need to type the full path. 
# Nginx Server Configuration — Serving React at /MallikEngineering/ subpath
server {
    listen 80;
    server_name _ 192.168.1.15 localhost; # Replace 192.168.1.15 with actual client server static IP

    client_max_body_size 500m;

    # ── 1. Redirect root / to /MallikEngineering/ automatically ──
    location = / {
        return 301 /MallikEngineering/;
    }

    # ── 2. React Frontend served at /MallikEngineering/ subpath ──
    # IMPORTANT: Use ^~ /MallikEngineering/ so React build assets (logos, images, JS) take precedence
    location ^~ /MallikEngineering/ {
        alias "C:/Users/Administrator/source/repos/Honda/Other Projects/Nginx demo/Mllik/MallikNewVersion/build/";
        index index.html;
        try_files $uri $uri/ /MallikEngineering/index.html;
    }

    # ── 3. API → Backend Proxy ──
    location /api/ {
        proxy_pass http://127.0.0.1:8000/api/;

        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";

        proxy_read_timeout 300s;
        proxy_send_timeout 300s;
    }

    # ── 4. Socket.io WebSocket Proxy ──
    location /socket.io/ {
        proxy_pass http://127.0.0.1:8000/socket.io/;

        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";

        proxy_read_timeout 300s;
        proxy_send_timeout 300s;
    }

    # ── 5. Uploaded Document Folders (Proxied to Node.js backend) ──
    location /contractReview/ {
        proxy_pass http://127.0.0.1:8000/contractReview/;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    location /uploads/ {
        proxy_pass http://127.0.0.1:8000/uploads/;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}

🚀 6. STEP-BY-STEP ON-PREMISES INSTALLATION & DEPLOYMENT GUIDE

Complete Setup Walkthrough

Follow these sequential steps when setting up the Mallik ERP stack on a fresh on-premises Windows Server machine:

1
Install Server Prerequisites (Node.js, MariaDB, Memurai Redis, Nginx)
  1. Node.js (LTS): Download & run Node.js installer or run winget install OpenJS.NodeJS.LTS. Verify with node -v.
  2. MariaDB Database: Install standalone MariaDB on port 3306 (or 3307). Set root password and import database schema:
    mysql -u root -p -P 3306 server_mallik < C:\path\to\database_dump.sql
  3. Memurai Redis Service: Install Memurai Developer (Redis Windows service) using winget install --id Memurai.MemuraiDeveloper -e. Verify service running on port 6379.
  4. Nginx Web Server: Download Nginx Windows binary (e.g., nginx-1.30.4.zip from nginx.org) and extract to C:\nginx\.
2
Configure, Package PKG (.exe) & Start Backend Server
  1. Open app/.env and set:
    APP_HOST = 127.0.0.1
    APP_URL = http://<SERVER_LAN_IP>
    APP_PORT = 8000
    DB_HOST = 127.0.0.1 (or database server IP)
  2. Verify app/server.js includes app.set("trust proxy", 1); right after const app = express();.
  3. Verify app/app/sockets/index.js sets origin: "http://<SERVER_LAN_IP>".
  4. Compile Backend to Windows Executable (.exe) via PKG:
    npm install -g pkg
    cd C:\path\to\app && pkg . --targets node18-windows-x64
    *(Generates server.exe in project directory)*
  5. Launch executable on server (ensure .env is in the same folder as server.exe):
    .\server.exe
3
Build Frontend React Production Bundle (for /MallikEngineering/ subpath)
  1. Open MallikNewVersion/.env and set relative paths:
    REACT_APP_API_URL=/api/
    REACT_APP_IMAGE_URL=/
  2. Open MallikNewVersion/package.json and set: "homepage": "/MallikEngineering/"
    ⚠️ This tells React to prefix all asset paths with /MallikEngineering/ in the build output — must match the Nginx location block exactly.
  3. Compile the production bundle:
    cd C:\path\to\MallikNewVersion && npm run build
4
Configure & Start Nginx Reverse Proxy (with /MallikEngineering/ subpath)
  1. Edit C:\nginx\conf\nginx.conf with the following key settings:
    • Set server_name _ <SERVER_LAN_IP> localhost; (the _ is a wildcard catch-all)
    • Add root redirect: location = / { return 301 /MallikEngineering/; }
    • Use alias (NOT root) for the frontend location block:
      location /MallikEngineering/ { alias "C:\path\to\MallikNewVersion\build\\"; try_files $uri $uri/ /MallikEngineering/index.html; }
  2. Test Nginx configuration syntax:
    C:\nginx\nginx.exe -t
  3. Start Nginx:
    C:\nginx\nginx.exe (or nginx.exe -s reload if updating existing instance)
5
Configure Windows Firewall Rule (Allow Port 80 Inbound)

Execute the following command in Administrator PowerShell to allow LAN client connections on Port 80:

New-NetFirewallRule -DisplayName "Allow Nginx HTTP Port 80" -Direction Inbound -Protocol TCP -LocalPort 80 -Action Allow
6
Configure Windows Services for Auto-Start on System Boot
  1. Nginx as Windows Service (via NSSM):
    nssm install Nginx "C:\nginx\nginx.exe" && nssm start Nginx
  2. Executable Backend (`server.exe`) as Windows Service (via NSSM):
    nssm install MallikBackend "C:\path\to\server.exe" && nssm start MallikBackend
7
End-to-End Verification
  1. Open browser on the server:
    http://localhost/ → auto-redirects to → http://localhost/MallikEngineering/ ✅
  2. Open browser on any LAN client PC:
    http://<SERVER_LAN_IP>/MallikEngineering/ ✅
  3. Test API directly from browser or Postman:
    http://<SERVER_LAN_IP>/api/user ✅
  4. Perform login, test data grid loads, and verify WebSocket connection in browser DevTools Network tab (Filter: WS).
