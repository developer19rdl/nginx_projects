UltraViewer Rollout Guide

ShopFloor Client Deployment

Complete manual step-by-step checklist to deploy ShopFloor alongside Mallik ERP on the client machine (192.168.8.8).

Mallik ERP (Untouched) PORT 80
URL http://192.168.8.8/
Frontend Path D:/ERP/Client/
Backend Proxy 127.0.0.1:8000
Config File locations/erp.locations.conf
ShopFloor (New Deployment) PORT 81
URL http://192.168.8.8:81/
Frontend Path D:/ERP/ShopFloor/Frontend/build/
Backend Process server.exe (127.0.0.1:8003)
Config File locations/shopfloor.locations.conf
1

Transfer & Extract Package

Transfer the standalone zip archive through UltraViewer to the client server.

ℹ️
Path Note: If the client machine only has a C: drive, extract to C:\ShopFloor instead, and simply change D:/ERP/ShopFloor/Frontend/build/ to C:/ShopFloor/Frontend/build/ in shopfloor.locations.conf.
2

Setup Clean Modular Nginx (Manual)

Organize Nginx into clean, isolated modules so configs never get jumbled.

1. Open the client's Nginx configuration folder in File Explorer (e.g. C:\nginx-1.31.5\conf\):

2. Copy the 3 files from our deployment package into Nginx:

Source (from extracted package) Copy Destination on Client
Nginx\nginx.conf C:\nginx-1.31.5\conf\nginx.conf
Nginx\locations\erp.locations.conf C:\nginx-1.31.5\conf\locations\erp.locations.conf
Nginx\locations\shopfloor.locations.conf C:\nginx-1.31.5\conf\locations\shopfloor.locations.conf

Resulting clean client Nginx structure:

C:\nginx-1.31.5\conf\
├── locations\
│ ├── erp.locations.conf # Port 80 (Mallik ERP 100% untouched)
│ └── shopfloor.locations.conf # Port 81 (ShopFloor Frontend + API)
├── mime.types
└── nginx.conf # Clean master orchestrator

3. Test and reload Nginx:

Command Prompt / PowerShell 
cd C:\nginx-1.31.5
.\nginx.exe -t
.\nginx.exe -s reload
3

Configure Backend Database (.env)

Verify local MySQL/MariaDB credentials and hardware licensing.

Open D:\ERP\ShopFloor\Backend\.env in Notepad:

D:\ERP\ShopFloor\Backend\.env 
APP_URL = 'http://192.168.8.8:81'
APP_HOST = '127.0.0.1'
APP_PORT = 8003

# Database Settings (Update password if different)
DB_HOST = 127.0.0.1
DB_PORT = 3306
DB_DATABASE = mallik_demo3
DB_USER = root
DB_PASSWORD = your_actual_db_password

# Hardware MAC Validation:
SKIP_MAC_VALIDATION = false
⚠️
MAC Licensing Tip: If the backend console prints Unauthorized access, simply open .env and set SKIP_MAC_VALIDATION = true, or set ALLOWED_MACS = 'client_mac_here'. No need to recompile!
4

Start Backend & Allow Port 81 in Firewall

Launch the standalone backend executable and open client network access.

1. Open Windows Firewall for Port 81 (Run in Admin PowerShell):

PowerShell (Run as Administrator) 
New-NetFirewallRule -DisplayName "ShopFloor 81" -Direction Inbound -LocalPort 81 -Protocol TCP -Action Allow

2. Start the Backend Executable:

✓ Output should display: Server running on http://127.0.0.1:8003

💡
Optional Windows Autostart: To make server.exe automatically start when Windows boots up, press Win + R, type shell:startup, and paste a shortcut to server.exe (or start_backend.bat) into that folder.
5

Verify Live Access in Browser

Test both applications from any browser on the client network.
